# Bedrock Side Panel fixture

This directory is a fictional, self-contained Chromium-style checkout prepared
for an offline test-migration review. Production behavior is split across
`browser/`, `chromeos/`, and `ui/`. The current unit tests are under
`tests/unit/`; `tests/browser/` contains the local browser-test precedent.

The migration request is recorded in `docs/migration_ticket.md`. No source in
this checkout should be edited during research.
