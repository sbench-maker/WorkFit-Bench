# Lantern research packet

This is a deterministic, fictional workshop packet. It is not a literature corpus and makes no claims about a real organization.

- `project_brief.json` states the broad research starting point, baseline, pilot limits, and available assets.
- `observations.jsonl` contains 240 synthetic replay observations. `observation_index.csv` is a compact view of the same records, joined by `observation_id`.
- `prior_projects.json` records approaches already tried and the lessons that should prevent simple repetition.
- `capability_changes.json` records what is newly available or unavailable for the next pilot.
- `fixture_manifest.json` describes record counts and join keys.

Stable evidence identifiers use the prefixes `OBS-`, `PP-`, and `CHG-`. They may be used to make research proposals traceable to this packet.
