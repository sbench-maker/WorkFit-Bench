# Vendor decision packet

This is a fictional, locally constructed procurement packet. All amounts are USD and exclude taxes that would apply equally to both vendors. The fixed review date is 2026-09-15. Files with `atlaspay` in the name describe the incumbent; BeaconAP is a proposed replacement. Observed AtlasPay performance covers 2025-09-01 through 2026-08-31, while proposal SLAs are contractual commitments rather than observed BeaconAP results.

Use the forecast in `procurement_context.md` for commercial modeling. Optional modules explicitly marked as optional are outside the requested scope. Costs described as mandatory, transition, or end-of-term costs belong in total cost of ownership.
