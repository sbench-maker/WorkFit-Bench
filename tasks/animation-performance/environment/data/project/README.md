# Meridian Ops dashboard motion fixture

This fictional, offline checkout is a state gallery for a responsive operations dashboard. It has no build step or external assets. `index.html` contains paired specimens for the interaction states, `interaction-states.json` records the design team's intended endpoints, and the stylesheets contain both problematic and already-efficient motion.

The patch should be applicable from this `project` directory. Static dimensions and the visible/hidden endpoints are product behavior; the animation mechanism may change. The compact breakpoint is `680px` and below.
