# OrbitDesk planning fixture

This directory is a deterministic, fictional product-planning fixture. `feature_spec.md` is the approved feature brief and `repo/` is a read-only snapshot of the relevant parts of the existing OrbitDesk monorepo. The snapshot is intentionally partial: files named in `repo_snapshot.json` are the in-scope codebase evidence.

No record or organization in this fixture represents a real person, company, or observation.
