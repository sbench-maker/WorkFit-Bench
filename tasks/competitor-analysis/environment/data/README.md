# Frozen research packet

This is a deterministic, fictional competitive-intelligence snapshot dated 2026-06-30. It contains no live observations and should be analyzed only from the bundled files.

NimbleSignal's direct market is hosted product-behavior analytics for EU B2B SaaS companies with 100-2,000 employees. A direct competitor must solve the combined core job of event analytics, funnels/retention, and session replay; offer a vendor-hosted cloud product; serve a customer range that overlaps NimbleSignal's; and support EU data residency by the snapshot date. Products that solve only one component, are self-host-only, or target only enterprise customers are adjacent alternatives.

Use records observed on or before the snapshot date. `available` is generally available, while `beta`, `announced`, and `roadmap` are not full availability. Blank facts remain unknown. Where dated structured records conflict, the most recent non-withdrawn record in force on the snapshot date governs. Customer feedback is directional evidence, not a verified product fact; rows with `duplicate_of` repeat another account and should not be counted twice.

Every record has a local evidence ID. Material factual claims should point to these IDs so a reviewer can trace them. Files use stable vendor IDs as join keys.
