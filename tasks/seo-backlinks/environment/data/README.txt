This directory is a deterministic fictional point-in-time backlink export; no record is a live observation.
Join backlinks.source_domain to referring_domains.domain and join destination_site + destination_path to site_pages.
verification_status values are verified_active, verified_removed, and unverifiable_js. The last is unknown, not removed.
Profile and link-gap counts use verified_active backlinks. A referring domain is counted once per destination site.
Authority scores are 0-100. Raw penalty, indexing, PBN, hacked-content, paid-placement, page-depth, and outbound-link fields are supplied as evidence; no precomputed risk label is included.
Anchor categories must be inferred from site_context.json. Check URL anchors before branded terms, then exact keyword, generic phrase, partial phrase, and natural/long-tail.
The snapshot has no historical series, traffic measurements, or live-crawl results.
