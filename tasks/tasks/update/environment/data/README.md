
# Offline update snapshot

All names, projects, messages, and records in this directory are fictional and locally constructed. `context.json` identifies the user and fixed snapshot date. `project_tracker.csv` is the frozen tracker export; `recent_activity.jsonl` is the complete activity window; `workspace/` is the current task and memory state. `review_decisions.csv` records Maya's decisions after reviewing the proposed task and memory changes, so those rows are the only authorized changes. A `decline` or `leave_unresolved` row is explicit non-authorization. Source references are stable local evidence identifiers, not network locations.
