# Alder Peak finance design

## Color

Use only these palette tokens in the report CSS:

- `--ink: #13211c`
- `--muted: #65716b`
- `--paper: #fffdf8`
- `--canvas: #eef2ed`
- `--line: #d8ded9`
- `--accent: #176b55`
- `--accent-soft: #dceee7`
- `--positive: #176b55`
- `--negative: #a5453d`
- `--warning: #9a6a12`

## Typography

Headings may use Georgia with a system-serif fallback. Body copy and numeric labels should use system sans-serif and tabular numerals. Do not load remote fonts.

## Layout

Use a centered report surface no wider than 1100px, a four-card KPI row on desktop, and a compact two-column analysis area for charts. Below 760px, allow cards and chart panels to stack and tables to scroll rather than clip.

## Components

Use restrained borders, one consistent card radius, clear positive/negative status treatment, and an internal-finance confidentiality badge. Use the accent for primary data emphasis, not decoration.
