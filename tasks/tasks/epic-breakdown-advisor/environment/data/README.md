# Supplier returns planning fixture

All entities and observations in this directory are fictional and were constructed locally for backlog planning.

- `epic.json` contains RET-410, its INVEST context, capability scope, and non-goals.
- `workflow.json` describes the full user-visible journey and the simplest complete path.
- `business_rules.json` contains policy constraints that acceptance criteria must preserve.
- `team_constraints.json` contains the sprint ceiling, relative estimates, and known uncertainty.
- `discovery_observations.csv` contains 240 frozen discovery signals. `requested_capability` is the primary feature signal; frequency and `value_rating_1_to_5` can inform sequencing or deferral.
- `generation_notes.json` documents construction counts and deliberate boundary cases, not expected planning answers.

The non-domestic region labels are fictional operating regions. No record represents a real person, company, or observation.
