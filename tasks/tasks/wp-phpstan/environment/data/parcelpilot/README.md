# ParcelPilot fixture

ParcelPilot is a fictional WordPress plugin that sends WooCommerce orders to regional carriers. The repository has a Composer script for its static-analysis gate and checked-in offline fixtures for the APIs it integrates with.

The `build/` directory is generated by the release pipeline. The `vendor/` directory contains the analyzer launcher and small stub fixtures, not first-party plugin code. The loyalty bridge is optional at runtime and is guarded before the integration class is instantiated.
