# PilotDesk support snapshot

All names, accounts, tickets, policies, and tool responses in this directory are fictional and were constructed locally for this exercise. The fixed operating date is 2026-06-30. `historical_tickets.json` contains representative helpdesk traffic; it is context for designing the agent, not a queue of tickets to answer individually.

The import artifact must follow `deployment_contract.json`. Product facts come from `knowledge_base.json`; refund decisions come from `refund_policy.json`; escalation destinations come from `support_policy.json`; and tool capabilities and result states come from `tool_catalog.json`.
