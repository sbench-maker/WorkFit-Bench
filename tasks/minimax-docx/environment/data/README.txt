This directory contains a fictional, frozen release-review fixture.

draft_change_packet.docx is the content source. Preserve its deployment,
verification, rollback, and approval scope.

corporate_release_template.docx is the formatting authority for page setup,
styles, header, footer, and tables.

release_facts.json is the factual authority wherever the draft contains a
placeholder, an obsolete value, or a conflicting value. No network access or
external data is needed.
